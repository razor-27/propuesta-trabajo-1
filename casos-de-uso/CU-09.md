```mermaid
sequenceDiagram
    autonumber
    actor U as Usuario (Médico/Admin)
    participant Auth as Servidor IAM / Keycloak
    participant GW as API Gateway
    participant Audit as Servicio de Auditoría
    participant DB as BD Logs Auditoría

    U->>Auth: Iniciar sesión (Credenciales + MFA)
    Auth-->>U: Retorna Token JWT firmado
    U->>GW: Petición con Header Authorization: Bearer <Token>
    GW->>GW: Validar Token y Permisos RBAC
    GW->>Audit: Registrar evento de acceso (IP, Usuario, Recurso)
    Audit->>DB: Persistir Log inmutable
    GW->>GW: Enviar petición al microservicio correspondiente
